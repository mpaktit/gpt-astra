# Roadmap

## v1.0: Client game (this release)
Engine, 6 species, 6 sectors, 3 modes, rivals, economy, caches, pass, missions, achievements, cosmetics, PWA, CI, tests.

## v1.1: Polish from playtests
- Browser playtest pass: layout, feel and balance fixes
- Onboarding: a 30-second interactive tutorial run
- Haptics on mobile, controller support
- Localization scaffolding

## v1.2: Accounts and backend
- Auth plus cloud save (Supabase)
- Server wallet and ledger
- Replay-verified global and friends leaderboards, Daily Rift rankings

## v1.3: Real payments
- Stripe Checkout plus webhooks, crystal packs, starter pack, pass
- Receipts, refunds, parental controls

## v2.0: Social and live ops
- Season 2 (new species, sector and pass), remote-configured events
- Ghost races against friends' replays, shareable replay clips
- Clubs and co-op rifts
- Native wrappers (Capacitor) for iOS and Android stores
